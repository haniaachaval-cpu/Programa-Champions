Programa Champions IA · OCASA · Mes 3 · Claude Code

Dos semanas para que Claude trabaje sobre tus archivos

Claude Code es Claude trabajando directamente en una carpeta de tu computadora: lee, crea y modifica archivos, y arma herramientas completas a partir de lo que le pedís. En dos semanas lo vas a instalar, le vas a dar el contexto de tu área y vas a construir una herramienta chica que puedas usar.

Marcá lo que vas completando: queda guardado en este navegador. Cada módulo equivale a una semana y tiene su propia página. El índice te lleva directo al que te toca.
